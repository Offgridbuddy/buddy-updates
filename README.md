# Buddy Family Updates

The updates shelf for the Buddy family of apps, by **Off Grid Buddy Solutions**.

- **People** open the page: <https://offgridbuddysolutions.github.io/buddy-updates/>
- **The apps** read the same page's built-in `buddy-updates` list, and the
  standalone copy of that list lives at `updates.json` in this repo.
- App install files live in `apks/`; web editions live in `web/`.

Reading this shelf is open — the apps fetch without any key, and the files
are not secrets. **Changing** anything here takes the owner's GitHub
sign-in (password or fingerprint passkey). Nobody else can put a file on
this shelf.
